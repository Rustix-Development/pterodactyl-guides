# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/Rustix-Development/pterodactyl-guides/security/advisories/new), or by email to mohamed@rustix.xyz.

Include the extension version, your panel version and the steps to reproduce. You'll get a reply as soon as possible, and a fix will be released before the issue is made public.

## Supported versions

Only the latest release gets security fixes.
